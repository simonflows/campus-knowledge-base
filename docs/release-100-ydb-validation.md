# Проверка Document API для 1.0.0

26 ноября 2026 года, завершено в 06:52 по Екатеринбургу. Проверка выполнена на YDB через шлюз с синтетической меткой и отдельным префиксом таблиц. Рабочие таблицы и рабочий контейнер оставлены без изменений со стороны этой проверки.

| Что проверено | Результат |
| --- | --- |
| Миграция через `docker compose exec -T app npm run db:migrate` | Созданы 11 тестовых таблиц. YDB приняла TTL по `expiresAt` для сессий и квот. Повторный запуск прочитал `ENABLED` для обеих таблиц без повторного включения. TTL таблицы идентичностей остался `DISABLED`. |
| `npm run check:deploy-storage` | Все 11 таблиц доступны, первичные ключи совпадают со схемой. |
| `applies TTL and recovers conditional transaction outcomes` | SDK получил `TransactionCanceledException` без `CancellationReasons`. Условный отказ обработан по согласованному чтению затронутых записей. Заполненный счётчик не изменился, второй счётчик не появился. |
| `scripts/test-auth-100-fixture.ts` и `integrates OAuth and atomic author storage limits` | Прошли парольный вход и восстановление, одноразовость OAuth, конкурентное создание одной идентичности, отзыв сессий, проверка версии при назначении роли и сохранении черновика, отказ по квоте без частичной записи. OAuth-ответы и письмо подставлены тестом, хранилище реальное. |
| `snapshots and restores all eleven tables in an isolated prefix` | Снимок и восстановление 11 таблиц прошли. Сверены контрольные суммы всех таблиц и всего архива. Активные записи и постоянные счётчики сохранились, истёкшие к моменту снимка отсутствуют. Суммы остальных девяти таблиц совпали до и после добавления тестовых строк TTL. |

YDB включает `expiresAt:N` в описание таблицы после включения TTL и возвращает `ValidationException` при записи строкового значения в это поле. Архив учитывает служебное описание `expiresAt:N` только для двух объявленных TTL-таблиц с прежними ключами. Формат архива и ключи восстановленных таблиц остались прежними.

При одном последовательном прогоне два сценария получили HTTP 503 на обычных чтении и записи сессий. Причина не установлена. Повтор проверки OAuth и черновиков с диагностикой класса ошибки и времени операции прошёл. Затем отдельно прошёл обычный повтор проверки аккаунтов. Контрольные суммы сравнивались внутри теста, содержимое архива и значения строк в журнал не выводились.

## Воспроизведение

После подготовки изолированных таблиц командой миграции установить `CAMPUS_QA_DISPOSABLE=yes`, `CAMPUS_QA_MARKER` из `npm run --silent qa:mark-fixture` и `CAMPUS_QA_EXPECT_TTL=yes`. Хостовые тесты обращаются к отмеченной базе через loopback. Запускать после завершения других пишущих тестов.

```sh
npm run check:deploy-storage
node --import tsx --test --test-concurrency=1 scripts/test-auth-100-fixture.ts scripts/test-account-integration-100.ts
```
