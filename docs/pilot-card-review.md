## Допуск к импорту

- Координатор отмечает отдельно утверждённые формулировки и спорные поля. Для каждого числа фиксируются единица, год, статус факт или план и первичный документ.
- Владельцев карточек связывают с персональными учётными записями. Для совместной карточки нужно согласование каждого участвующего вуза.
- Утверждённый JSON сначала проверяется на одноразовой базе. После снимка рабочей базы команда импорта запускается без записи для сверки состава. Запись в рабочую базу выполняется после согласования публикации набора. [Процедура импорта](../DEPLOY.md)
