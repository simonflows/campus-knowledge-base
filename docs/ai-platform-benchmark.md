## Что проверено

В разделе «Полигон Yandex vs Alibaba» воспроизводятся три контрольные задачи на одном фиксированном наборе открытых материалов. Локальный эталон сверили с источниками и проверили через API пилота. В среде приёмки оба облачных подключения были не настроены. Ответов моделей, времени отклика, фактических затрат и статистики ошибок пока нет. Оценка интерфейсов ниже опирается на документацию платформ.

Набор [campus-public-2026-11-v1](../lib/benchmark.ts) содержит краткие выдержки по проектам и инфраструктуре. Площадь и этап УНК зафиксированы на дату использованных публикаций. В полигон входят только подготовленные факты об организациях и проектах. Клиент передаёт идентификатор сценария и режим запуска. Свободные запросы и выгрузки рабочей базы не передаются.

### Как добрать облачные измерения

Подключите провайдеров через секреты среды. Администратор пилота запускает оба API из раздела «Полигон». Для каждого сценария температура 0,05, предел 1200 выходных токенов, для статьи — 2200. Запишите версии, регион, пройденные пункты, редакторские замечания, время, токены и сбои. Для оценки устойчивости повторите минимум три раза с интервалом в минуту и сравните медиану. Для демовхода требуется PIN администратора. Лимит приложения — шесть запусков в час на процесс, до шести вызовов моделей за запуск. Для многорепликового развёртывания ограничьте расход у провайдеров.
