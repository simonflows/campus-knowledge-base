7. ВСТРОЙ ИИ В САМИ СЦЕНАРИИ

Не ограничивайся дополнительной кнопкой «Спросить Flash». Спроектируй и реализуй полезную интеграцию в обычные действия:

- Аналитика: при отправке естественного запроса модель помогает получить структурированные критерии; приложение проверяет и исполняет их штатным движком.
- Проверка текста: модель помогает выделять утверждения и контекст для сверки с доступными утверждёнными карточками.
- Редактор: использует утверждённые версии источников, помогает переписать выделенный фрагмент и собрать варианты площадок с сохранением источников.

При необходимости добавь предложение структуры карточки из предоставленного текста. Оно всегда остаётся предложением до проверки человеком.

Сначала изучи имеющийся клиент Yandex и Flash, затем расширяй его. Не добавляй другой провайдер или отдельный чат без необходимости.

Обязательные свойства:
- ИИ встроен в понятное действие пользователя и имеет видимый режим работы;
- никакой отправки каждого нажатия клавиши или скрытого постоянного опроса;
- передача текста в AI Studio прозрачна пользователю;
- модель получает только разрешённые этому пользователю данные;
- только утверждённые карточки служат основанием официальных фактов;
- явные фильтры пользователя не подменяются;
- числа и состав аналитической таблицы рассчитывает приложение;
- ответы модели проходят структурную и смысловую проверку;
- инструкции внутри источников считаются данными;
- модель не согласует, не публикует и не изменяет права;
- есть таймауты, лимиты, отмена устаревших запросов и защита от повторных вызовов;
- при отказе ИИ основные функции сохраняют работоспособность;
- неподтверждённое утверждение не становится подтверждённым только по мнению модели.

Не обещай автоматическое доказательство достоверности любого текста. Неразрешённые случаи явно направляются на ручную сверку.

Автотесты не должны расходовать платный API. Живую приёмку выполняй только в разрешённом тестовом контуре с действующими лимитами. Если его нет, точно отметь непроверенную часть.
