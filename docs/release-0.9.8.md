# Канон 0.9.8 — итог выпуска

Опубликован на [canon.midis.ru](https://canon.midis.ru/). Публичная приёмка выполнена 24 ноября 2026 в 05:04 (Екатеринбург, UTC+5): версия 0.9.8, готовность хранилища и контрольные запросы прошли. Контейнер healthy, запись открыта, restart policy — unless-stopped. Рабочие данные сохранены. Код, процедура установки и доказательства прошли независимое ревью; существенных противоречий не найдено. Непроверенные сценарии перечислены отдельно.

## Что изменилось

- Смысловая проверка разделяет извлечение утверждений, поиск утверждённых источников и проверку доказательств. Длинный текст обрабатывается целиком по частям, с контекстом и точными позициями цитат. Мнения, вопросы и фрагменты вне предмета проверки отделяются от фактов.
- Подтверждение и опровержение привязаны к сущности, единице, времени и версии источника. Число не переносится из общей вместимости на другую очередь или кампус. Условие, отрицание и зависимое продолжение нельзя отбросить, назвав остаток внепредметным.
- Неполный ответ ИИ и недостаточная опора видны в охвате и unknown. Они не превращаются в разрешение публикации. Сохраняются полезные программные проверки чисел и предметных ограничений.
- Поток проверки показывает ход обработки, поддерживает отмену и не принимает обрыв соединения за успех. Перед финальным результатом повторно сверяется весь утверждённый набор источников.
- Сохранён прежний дизайн: пропорциональные мобильные контуры, спокойные переходы, неразрывные числовые группы, показатели из актуального паспорта и дополнительная информация при наличии утверждённых сведений.
- Понятнее редактор и «Моя работа», создание черновика доступно на телефоне. «Инфоповоды» заменены на «Подборки для публикаций». Роли, согласование и остальные функции сохранены.
- Помощник получил новое окно и три меняющихся примера. Набранный вопрос сохраняется. Если паспорт содержит только число вузов, запрос списка ведёт к разделу резидентов без вымышленных имён.
- Версия в подвале открывает краткие изменения; клавиатура, Escape и возврат фокуса проверены. Демо обозначено явно, выход читается на телефоне.

Интервью и цитаты сохраняют авторский текст. Полная свободная генерация интервью нейросетью не заявляется: для свободных материалов действует точечная правка, короткая проверяемая формулировка по карточкам сохраняет существующий опциональный ИИ-режим.

### Реальный ИИ и пределы доказательств

Длинный прогон настоящего Flash выполнялся с публичным тестовым набором карточек: 17 618 знаков, все 244 разных фрагмента прошли разметку, все 24 кандидата-факта дошли до сверки. За 85,454 секунды выполнено 18 вызовов: 12 extraction с ограниченным повтором пропусков и 6 verification. Приняты 20 допустимых заключений, 4 отклонены; семантический охват 240/244, режим mixed, итог 14 жёлтых и ни одного красного/зелёного. Финальный код повторно воспроизвёл все 18 точных оплаченных входов, также прошёл replay шести коротких контролей. Это доказательство полного обхода материала, а не подтверждение достоверности всего интервью по рабочей базе.

Отдельно exact исправленный образ вызвал штатный Flash на 16 актуальных утверждённых карточках из YDB, без подставного провайдера и без записи. Итог комбинированной проверки: 3 400 мест — зелёный, 9 999 — красный, площадь без источника — жёлтый. ИИ ready, но mixed: в семантический охват засчитан только 1 из 3 фрагментов, полностью принятых batches — 0, транспортных отказов — 0. Программное подтверждение числа сохранено, два фрагмента не выданы за принятый семантический разбор. Один вызов: 6 260 input / 450 output tokens. Повторное чтение подтвердило неизменность версий источников.

В актуальном паспорте нет площади. Поэтому 123 и 114 тыс. м² оба остаются unknown; данные ради теста не дополнялись. ИИ ошибается, неподтверждённые факты требуют решения ответственного сотрудника.

## Публичная приёмка и инфраструктура

На доверенном HTTPS получили: version/ready/health/cards/search — 200; два контрольных fact-check и исправленный guest assistant — 200; ИИ без сессии — 401; чужой Origin — 403; неверное тело — 400; POST ready после открытия записи — 405 без freeze header. HTTP перенаправляется на канонический HTTPS с 308. Источники результатов 3 400/9 999 содержат version ID.

TLS 1.3, прежний сертификат действителен до 21 февраля 2027. Fingerprint `791c93ae9a578853d790b14d9c2dff432f48dc4be0d269976777739bf8713b14` совпал с baseline. Совпали Nginx hash `189dc600…` и domain runtime drop-in `3ebd001a…`; renew timer активен. TLS, Nginx, права и способ передачи секретов не менялись, значения секретов не читались.

Длительный авторизованный поток через рабочий Nginx остаётся непроверенным: штатной сессии сотрудника в Chrome нет, поля входа пусты. Cookies и QA credentials в prod не подделывались. Потоковый route, отмена/ошибки/обрыв, браузерный parser и настоящий Flash проверены раздельно. HTTPS в CI image fixture относится к Document API; приложение там вызывается по loopback HTTP. Это не подменяет проверку delivery heartbeat/progress через внешний ingress.

На ВМ осталось примерно 1,5 ГБ, занято 96%. Образы отката сохранены, сборки на ВМ не проводились. Перед следующим крупным выпуском нужно отдельно спланировать место; широкое удаление образов, контейнеров, логов или данных в этой задаче не выполнялось. Новый тест на 200 пользователей не проводился и не заявляется. Неизменённые рабочие протоколы Диска дополнительно покрыты изолированной проверкой реестров; новый реальный экспорт рабочего материала не выполнялся.

## Восстановление

Baseline повторного cutover — принятый первый образ 0.9.8 `8cb60c82fe5c087aa711b5b89a710e51893649eee7d4462e584e0f716d060e32`, revision `5da7cd0e3f80ccc2df360da372cef4cc113b784a`, run `f098n24a`. При установке helper проверил accepted proof, точные байты старых override и pin25, прежние gates, labels, restart и freeze. В ветке отката он повторно проверяет unit/pin/override до запуска baseline, затем health/restart/freeze после запуска. Эта ветка проверена имитацией отказов; реальные отказы production в f098n24b не создавались.

При обработанном отказе блокируется новый gate/restart, останавливается systemd, повторно обнаруживается возможный поздний кандидат. Останавливается только точный container ID с нужными image/run label. Удаляется исключительно собственный pin26, прежний pin25 сохраняется. Данные назад не откатываются. Старые tombstone-unaware 48ce/0.9.5 writers запрещены.

При SIGKILL/сбое питания обработчик не гарантирован. Отсутствие accepted.json не доказывает закрытие writer: сначала сверить active pin/container/restart/freeze, затем при необходимости остановить подтверждённый кандидат и выполнить совместимое восстановление. Run IDs и каталоги не переиспользовать. Исполненный one-shot helper повторно не запускать; следующий выпуск требует новой проверенной baseline.

Первый операционный cutover f098n24a и его backup сохранены. После него реальная проверка выявила ошибки границ/контекста и sparse assistant, которые исправлены PR8. Первые failed CI45281479128/45281520031 и smoke-логи не считаются успешными; история — в Git и [навигаторе подготовки](progress-history-098-before-correction.md).
