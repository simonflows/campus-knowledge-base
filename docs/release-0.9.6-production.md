## ИИ и границы качества

Пять вызовов настоящей модели без автоматических повторов: fact, KUKA analytics, passport analytics и chat дали полезные ответы с проверенной опорой; editor сохранил исходный заголовок. Итого 5ready/safe,4useful. Источники/полные поля/версии проверяет сервер. Модель не получает право переписывать карточки и публиковать статьи. Неподтверждённые ответы отклоняются, обычный результат сохраняется.

Editor fixture проверяет точный утверждённый заголовок/атрибуцию. Он **не подтверждает качество свободного переписывания полной статьи**: новый текст здесь не получен. Полные проверки редактора/чисел/ссылок/согласований проходят локально и в fixture, но это другая область доказательств. Всего за этап 22 платных вызова с учётом старых кандидатов и диагностик.

## Нагрузка и защита

По последнему поручению владельца 200 отложен. Normal:7preflight+8+8=23,0 ошибок. Peak:7preflight+однаволна 50=57, observed in-flight50,0 ошибок/повторов, elapsed1504ms, наибольший p95 по маршрутам 1499ms. Маршруты ready/search/cards/analytics/fact-check. Точный образ, изолированная копия реальной YDB, синтетический сотрудник, безAI/Диска.

Это loopback-проверка приложения, обходящая внешний ingress. Она не подтверждает 50 платных AI/Disk операций одновременно, длительную нагрузку,50 реальных логинов или 200 пользователей. Прежние неудачные 200/190 и первый peak другого кандидата сохранены; первопричина всех прежних интермиттирующих 503 не доказана.

Nginx/UFW/Fail2ban проверены только чтением: config valid, для limit_req/limit_conn настроен ответ 429; UFW active/443allow/SSHlimit. Настройки не отключались и не ослаблялись. Диск не участвовал в нагрузке, его тариф не объясняет 503 этого теста. Живые AI диагностики вернулиHTTP200; отказы качества были на уровне проверяемого ответа модели.
