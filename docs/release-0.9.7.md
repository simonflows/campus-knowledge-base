# Канон0.9.7 — удобство демо и результатов проверки

Статус: UI реализован и проверен локально, CI и установка ещё впереди. Основание — последние прямые поручения владельца; [краткий контекст](context-0.9.7.md).

## Изменения
- Единственная кнопка «Попробовать в демо-режиме» — на странице входа, включая поддерживаемый режим legacy demo login. Из шапки вход в демо убран.
- У выхода из демо читаемые надписи и состояния наведения/фокуса; индикатор текущего демо сохранён. Измеренный контраст15.40:1 в покое,13.66:1 при наведении/фокусе.
- «Запросы на подтверждение» закрыты по умолчанию, заголовок/счётчик всегда видны. Мышь, Enter и Space раскрывают/сворачивают; правила согласования и обработчики не менялись.
- Готовый rewrite расположен до длинного разбора. После успешного явного переписывания фокус/прокрутка ведут к заголовку под закреплённой шапкой. Обычная проверка, редактирование, ошибка, пустой и запоздалый ответ не прокручивают страницу. Подробности исходной проверки сворачиваются; предупреждения, исключённые фрагменты и источники сохранены.
- Версия package/lock и OCI label —0.9.7; проверки метаданных сравнивают API с актуальной версией package.

## Проверки
- Host check/build и полный offline PASS,246тестов. Браузерный helper с success/error/stale/empty/reduced-motion/Markdown/390px включён в свежий CI fixture; контраст выхода проверяется в реальном CSS.
- Native disclosure проверен с11synthetic карточками и на демо-координаторе. Демо не делает рабочие API-запросы, выход сохраняет рабочую сессию.
- Независимое UI-ревью прошло. Найденный случай исчезновения CTA при legacy demo login закрыт SSR-регрессией в обоих режимах; тест требует отсутствие синтаксических ошибок компилятора.

## Совместимость и данные
Серверная логика, API-обработчики, схема, роли, зависимости и канонические данные совпадают с принятым061. Меняются только UI, тесты/документы и metadata версии. Проверки ИИ/YDB/Диска061 наследуются явно через равенство защищённых Git-поддеревьев и нормализованных зависимостей. Новые платные AI-вызовы из-за косметики не выполняются и не заявляются.

Перед установкой предусмотрены свежий согласованный снимок восьми таблиц, проверка архива, временный запрет записи при первом старте и сравнение inventory. Восстановление CLI уже доказано для061 и применяется при неизменном CLI. При неудаче разрешён только совместимый откат приложения к061, без отката данных;48ce/0.9.5 writer запрещены. Nginx/firewall не меняются.

Полные идентификаторы установки и финальные публичные проверки будут добавлены после выполнения. После сохранения/публикации результатов пользователь прямо поручил обычное выключение ПК без принудительного закрытия несохранённых приложений.
