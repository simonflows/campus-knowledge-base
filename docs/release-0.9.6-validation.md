Ожидания доступа и фактчекинга не ослаблялись. Dev localhost8080 сохранён.

На GitHub main включены PR и обязательный актуальный `Quality gate`, в том числе для администратора; force push/deletion запрещены. CI уже содержит lint/typecheck/offline/build, DynamoDB/browser fixture и точный Docker-image test. Запуск на release commit и слияние ещё предстоят.
